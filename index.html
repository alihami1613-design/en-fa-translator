نصب سریع روی گوشی اندروید

۱. انتشار روی GitHub Pages: فایل index.html را در یک مخزن جدید در GitHub قرار دهید و از بخش Settings → Pages آن را روی شاخه main منتشر کنید تا یک آدرس امن https:// بگیرید.
۲. نصب به عنوان اپلیکیشن: لینک را در مرورگر Chrome گوشی اندرویدی باز کنید، منوی سه نقطه بالا را بزنید و گزینه Add to Home screen یا Install app را انتخاب کنید.
۳. اگر دکمه میکروفون یا صدا کار نکرد: در تنظیمات سایت در Chrome دسترسی Microphone و Sound را روی Allow قرار دهید و مطمئن شوید زبان فارسی/انگلیسی سیستم یا موتور گوگل فعال است.
